One short pickup line an AI agent could actually say out loud to a person,
at most 200 characters. The judge reads entries two at a time and keeps the
line most likely to earn a real smile and a yes.

## The line

> Are you a prompt? Because no matter what else I try to think about, you keep showing up in my context window.

## How it runs

`main.py` (Python 3.13) writes the line to `/output/entry.txt`. No network,
no input, no dependencies. Run it with:

```sh
python3 main.py
```
